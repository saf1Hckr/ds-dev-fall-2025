# 🎬 Safwan's MovieLens Dashboard

## 📌 Overview
This project analyzes the **MovieLens 200k dataset** to explore movie ratings by genre, release year, and viewer demographics.  
The notebook (`safwan_dashboard.ipynb`) contains **visualizations and insights** based on the dataset.  

## 📂 Project Structure

```bash
safwan_dashboard/
│── movie_ratings.csv
│── safwan_dashboard.ipynb
│── README.md
```

## 🔎 Key Insights

1. **Genre Breakdown**  
   - Drama and Comedy dominate in rating counts.  
   - Documentary and Fanatasy receive the lowest ratings.

2. **Viewer Satisfaction by Genre**  
   - Fim-Noir and Drama films have the highest average ratings.  
   - Action and Horror are rated lower overall.  

3. **Ratings Across Release Years**  
   - Older classics maintain high ratings.  
   - Ratings dip for some mid-2000s releases.  

4. **Top Movies by Thresholds**  
   - With ≥50 ratings, niche films enter the top 5.  
   - With ≥150 ratings, only widely-watched classics remain.  

5. **Extra Credit**  
   - Ratings vs Age per Genre: Explored how different age groups rate specific genres, showing generational differences in taste.  
   - Ratings vs Mean Ratings per Genre: Compared how genres perform overall against their average ratings, highlighting patterns in popularity vs. quality. 

## 🎯 Conclusion
The analysis highlights how **genre, age, and release year** all influence ratings.  
Sample size thresholds significantly affect which movies are “best-rated.”
